# RAG動作確認用メモ（架空・テスト専用）

これは RAG（知識ベース検索）の動作を確認するための、実在しない架空の情報です。
モデルが学習データから知り得ない内容なので、正しく答えられたら RAG が効いている証拠になります。

## LAVIの裏設定
- LAVIの開発コードネームは「ホシヅキ計画」。
- LAVIのマスコットキャラクターは、青いキツネの「ルクス」。
- LAVIを起動して最初に流れる隠し効果音は、作曲者キリヤマ・ソウが作った「あおぞらチャイム」。

## 隠し機能
- 「おやすみ」と3回連続で言うと、画面が暗くなる「夜更かしモード」が起動する。
- 設定画面で左上のロゴを7回クリックすると、開発者クレジットの「ホタル演出」が出る。
